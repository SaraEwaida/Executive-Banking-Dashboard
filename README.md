# Executive Banking Dashboard - Final Project

End-to-end BI solution: database analysis, SQL, Excel prep, Power BI
dashboard, DAX measures, and a business-insights report.

## Structure
- Part1-Database-Analysis  : ER diagram and table analysis
- Part2-SQL                : schema/data and business queries
- Part3-Excel              : validation, pivots, Power BI-ready data
- Part4-5-PowerBI          : Power BI project (.pbip) + DAX measures
- Part6-Business-Insights  : one-page insights report
- docs                     : assignment brief and build guide

## Opening the dashboard
Open Part4-5-PowerBI\Banking_Executive_Dashboard_PBIP\"Banking Executive Dashboard.pbip"
in Power BI Desktop, then click Refresh once. Keep the .SemanticModel and
.Report folders next to the .pbip - the .pbip depends on them.
