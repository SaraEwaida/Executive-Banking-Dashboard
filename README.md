# Executive Banking Dashboard - Final Project

An end-to-end Business Intelligence solution over a retail-banking
database: database analysis, SQL, an Excel data-prep workbook, an
interactive Power BI dashboard, DAX measures, and a business report.

## Folders
- Part1-Database-Analysis  : ER diagram and table analysis
- Part2-SQL                : schema/data and business queries
- Part3-Excel              : validation, pivots, Power BI-ready data
- Part4-5-PowerBI          : Power BI dashboard and the 37 DAX measures
- Part6-Business-Insights  : one-page insights and recommendations

## HOW TO OPEN THE POWER BI DASHBOARD  [please read]

The dashboard is a Power BI PROJECT - it is a FOLDER, not one file.
Clicking the .pbip on GitHub will NOT open it. You must download the
whole folder first.

1. Easiest way: on the repository home page click the green "Code"
   button, choose "Download ZIP", then unzip it.
2. Go to  Part4-5-PowerBI\Banking_Executive_Dashboard_PBIP
3. Keep every file together - do NOT remove the .SemanticModel or
   .Report subfolders. The .pbip depends on them.
4. Open  "Banking Executive Dashboard.pbip"  in Power BI Desktop.
5. Click Refresh once on the Home ribbon - all data and all 7 pages load.
