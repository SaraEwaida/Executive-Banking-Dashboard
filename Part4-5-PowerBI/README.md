# Power BI Dashboard - How to open

This dashboard is a Power BI PROJECT - a FOLDER, not a single file.
Clicking the .pbip on GitHub will not open it.

TO OPEN:
1. Download the whole folder  Banking_Executive_Dashboard_PBIP.
   Easiest: on the repo home page click the green "Code" button,
   choose "Download ZIP", then unzip.
2. Keep every file together - do not remove the .SemanticModel or
   .Report subfolders. The .pbip depends on them.
3. Open  "Banking Executive Dashboard.pbip"  in Power BI Desktop.
4. Click Refresh once - all data and all 7 pages load.

Also in this folder:
- Part5_DAX_Measures.md.pdf  : the 37 DAX measures
- Banking_Dashboard.html     : interactive preview you can open in a browser
